# Методология и Архитектура Микросервиса Перевода (RU→EN)

## 1. Общее описание

Микросервис представляет собой **stateless REST API** на фреймворке **FastAPI (Python 3.12)**, предназначенный для машинного перевода заголовков, анонсов и полных текстов новостей с русского языка на английский с соблюдением корпоративного глоссария.

Архитектура построена по паттерну **Controller — Service — LLM Client**, выровненному с корпоративным регламентом разработки (`AGENTS.md`).

---

## 2. Глоссарий и морфологический анализ (pymorphy3)

Для обеспечения фактологической точности и сохранности корпоративных терминов используется версионированный рантайм-глоссарий `transneft_glossary_v002` (122 официально утверждённых термина).

### Алгоритм сопоставления (Glossary Matching):
1. **Предварительный индекс**: При старте или вызове `POST /api/v1/glossary/reload` все термины и их синонимы (`ru_aliases`) лемматизируются с помощью `pymorphy3.MorphAnalyzer()` и сохраняются в память (`нормальная_форма_фразы → GlossaryTerm`).
2. **Извлечение н-грамм**: При поступлении текста новости сервис разбивает текст на слова, лемматизирует каждое слово и извлекает все 1..4-граммы нормальных форм.
3. **Сопоставление и ранжирование**:
   - Находятся пересечения н-грамм текста с индексом терминов.
   - Термины ранжируются по приоритету (`mandatory` > `preferred` > `optional`).
   - Отбираются наиболее релевантные термины и подмешиваются в системный контекст промпта.

## 3. Stateless HTTP LLM-клиент (LiteLLM / OpenAI REST API)

Микросервис работает в строго **Stateless-режиме**:

- **Протокол**: OpenAI Chat Completions REST API (`POST /v1/chat/completions`).
- **Инфраструктура**: Обращение к централизованному LiteLLM-прокси (`LITELLM_BASE_URL`), за которым стоят высокопроизводительные vLLM / SGLang серверы с моделью.
- **Локальная разработка**: В режиме разработки инференс поставляется отдельным автономным HTTP-сервером (`demo/mlx_server.py` на порту 8001), к которому микросервис обращается по сети.

---

## 4. Безопасность и M2M-авторизация

- Доступ к эндпоинтам `/api/v1/translate` и `/api/v1/glossary/reload` защищён обязательным заголовком `X-API-Key`.
- Значение ключа сверяется со значением `BITRIX_AUTH_TOKEN` из `.env` с использованием криптографически безопасного `hmac.compare_digest()` для защиты от атак по времени (timing attacks).

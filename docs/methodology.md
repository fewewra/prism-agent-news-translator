# Методология и Архитектура Микросервиса Перевода (RU→EN)

## 1. Общее описание

Микросервис представляет собой stateless REST API на фреймворке **FastAPI (Python 3.12)**, предназначенный для машинного перевода заголовков и текстов новостей ПАО «Транснефть» с русского языка на английский.

Архитектура построена по паттерну **Controller — Service — LLM Client**, выровненному с корпоративным регламентом разработки (`AGENTS.md`).

---

## 2. Глоссарий и морфологический анализ (pymorphy3)

Для обеспечения фактологической точности и сохранности корпоративных терминов используется версионированный глоссарий `transneft_glossary_v002` (115 официально утверждённых терминов).

### Алгоритм сопоставления (Glossary Matching):
1. **Предварительный индекс**: При старте сервиса все термины и их синонимы (`ru_aliases`) лемматизируются с помощью `pymorphy3.MorphAnalyzer()` и сохраняются в словарь `нормальная_форма_фразы → GlossaryTerm`.
2. **Извлечение н-грамм**: При поступлении текста новости сервис разбивает текст на слова, лемматизирует каждое слово и извлекает все 1..4-граммы нормальных форм.
3. **Сопоставление и ранжирование**:
   - Находятся пересечения н-грамм текста с индексом терминов.
   - Термины ранжируются по приоритету (`mandatory` > `preferred` > `optional`).
   - Отбираются Top-K терминов в зависимости от `glossary_mode` (`retrieved_top3`, `retrieved_top5`, `retrieved_top10`).

## 3. Гибридный LLM-клиент (Local MLX vs. LiteLLM)

Сервис поддерживает два взаимозаменяемых режима работы через абстракцию `BaseLLMClient`, переключаемых строкой в `.env`:

### Режим A: `LLM_BACKEND=local` (Локальная разработка и демо)
- **Модель**: MiLMMT 12B (`mlx-community/MiLMMT-46-12B-v0.1-4bit`).
- **Инференс**: Прямой вызов `mlx_lm` на чипе Apple Silicon.
- **Преимущества**: Полная автономия, высокая скорость (~3 сек на новость), отсутствие внешних сетевых зависимостей.

### Режим B: `LLM_BACKEND=litellm` (Корпоративный контур)
- **Протокол**: OpenAI Chat Completions API.
- **Инфраструктура**: Обращение к централизованному LiteLLM-прокси (`LITELLM_BASE_URL`), за которым стоят высокопроизводительные vLLM / SGLang серверы с моделью Qwen.

## 4. Безопасность и M2M-авторизация

- Доступ к эндпоинтам защищён обязательным заголовком `X-API-Key`.
- Значение ключа сверяется со значением `BITRIX_AUTH_TOKEN` из `.env` с использованием криптографически безопасного `hmac.compare_digest()` для защиты от атак по времени (timing attacks).
